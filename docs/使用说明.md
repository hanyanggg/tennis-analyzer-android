# Tennis Analyzer 使用说明

本说明适用于当前 Android 测试版本。应用的分析数据保存在手机本地；当前球场识别和球速估算都不需要联网。

## 1. 拍摄视频

为了提高球场识别和球速估算的稳定性，建议按以下方式拍摄：

- 手机横屏，画面比例使用 16:9。
- 手机放在底线后方中央，尽量与球场中线对齐。
- 使用三脚架或固定支架，拍摄过程中不要移动手机或变焦。
- 画面应包含完整的单打场地四角，球场线尽量清晰、无遮挡。
- 光线不足、强烈逆光、严重运动模糊都会降低识别精度。
- 建议先拍摄 10～30 秒的短视频进行测试。

## 2. 导入视频并查看动作

1. 打开 Tennis Analyzer。
2. 在首页点击“导入或拍摄视频”，或者进入“视频动作分析”。
3. 从手机相册中选择一段网球视频。
4. 使用播放、暂停、进度条、逐帧前进和逐帧后退查看动作。
5. 在需要的位置收藏关键帧，方便之后回看。
6. 点击“保存本次训练”，填写训练标题、动作类型和备注。

保存后的内容可以在底部“记录”页面查看。

## 3. 球速测算

在视频动作分析页面点击“开始测算”。测速分为球场标定和网球取点两个阶段。

### 3.1 选择球场模型

- **低机位模型**：适合底线后方的手机或三脚架画面，当前默认选择。
- **通用模型**：适合电视转播或较高机位画面。

切换模型会清除当前标定和测速结果，需要重新识别。

### 3.2 自动标定球场

1. 将视频暂停在球场线清晰、无遮挡的一帧。
2. 点击“用低机位模型识别当前画面”或“用通用模型识别当前画面”。
3. 识别完成后，检查画面上的四个角点和绿色边框。
4. 如果点位有偏差，点击“逐点修正 AI 标定”，再按页面提示依次点击：
   - 近端左侧单打底线角
   - 近端右侧单打底线角
   - 远端右侧单打底线角
   - 远端左侧单打底线角
5. 如果自动识别失败，也可以直接按上述顺序手动点击四个角点。

### 3.3 选择网球位置

1. 暂停在网球清晰的一帧，点击网球中心作为起点。
2. 使用“+1 帧”、进度条或播放按钮向前移动若干帧。
3. 再次点击网球中心作为终点。
4. 应用会显示估算球速、移动距离、时间差和结果可信度。
5. 确认后点击“使用这个结果”，球速会带回本次训练记录。

如果选点不准确，可点击“重选网球”；如果球场角点不准确，可点击“重新标定”。

## 4. 比赛数据记录

1. 从首页进入“比赛数据记录”。
2. 按实际比赛过程记录比分、回合和失误。
3. 完成后点击“保存比赛记录”。
4. 保存的比赛可以在“记录”页面查看。

## 5. 模型选择建议

| 拍摄方式 | 推荐模型 |
|---|---|
| 底线后方手机/三脚架 | 低机位模型 |
| 电视转播视频 | 通用模型 |
| 看台或较高固定机位 | 先尝试通用模型 |
| 角点识别明显偏移 | 切换模型后重新识别，或人工修正 |

无论使用哪一种模型，都应在测速前人工检查四个角点。

## 6. 当前限制

- 球场角点已经支持 AI 自动识别，但网球轨迹还不能自动跟踪。
- 球速是单摄像头的地面投影估算，不是三维测速。
- 网球飞行高度、相机偏斜、运动模糊和选点误差都会影响结果。
- 当前结果适合训练分析和版本测试，精度低于专业测速雷达。
- 低机位模型仍需要更多真实手机视频验证，尤其是夜场、逆光和不同颜色球场。

## 7. 常见问题

### 自动识别失败怎么办？

暂停到球场线更清晰的一帧，确认视频为横屏 16:9，并检查画面是否包含完整场地。仍然失败时可以切换模型或手动标定。

### 识别成功但角点不准怎么办？

点击“逐点修正 AI 标定”，按提示重新点击四个单打底线角。不要在角点错误时继续测速。

### 球速明显过高或过低怎么办？

检查球场角点是否正确、两个网球点是否点在球心，以及两个画面是否相隔太近。建议增加取点时间间隔后重新测量。

### 是否只能在 Vivo 手机上使用？

不是。应用是通用 Android 应用，当前已在 Android 虚拟机和 Redmi K40 上通过测试。不同品牌和型号仍需要逐步验证性能和相册兼容性。

### 拔掉数据线后还能使用吗？

可以。应用安装完成后可独立运行。数据线只在安装新版本、读取测试日志或调试时需要。
